# Phase 5 Owner-Prep Checklist

**Time required:** ~60 minutes (Snipcart account creation + dashboard configuration + Sanity schema apply + 1 deploy preview redeploy with the test key)

- [ ] Register `product` in `schemas/index.js`.
- [ ] Run `sanity dev` locally; verify "Product" appears in the schema list.
- [ ] Run `sanity deploy` to push to production.
- [ ] In Sanity Studio, publish AT LEAST 2 test products with these characteristics:
  - One product with `stockQuantity = 5`, `processes = [laser]`, 1+ images.
  - One product with `stockQuantity = 2`, `processes = [print]`, 1+ images. (For the low-stock UI test.)
  - (Optional) One product with `stockQuantity = 0`, `processes = [laser]`, 1+ images. (For the sold-out UI test.)
  - Each product needs: name, slug (auto-generated from name), description ≤200 chars, price (number), at least 1 image with alt text, processes (1+ refs).

## B. Snipcart account + dashboard config

- [ ] Create account at https://app.snipcart.com/register if not already done.
- [ ] Enable 2FA: Account → Security.
- [ ] Verify pricing tier: Account → Plan. Confirm RESEARCH assumption A1 (free under $X/month + 2% on top of Stripe; owner has acceptable expectations).
- [ ] **Test-mode keys:** Account → API Keys → copy the **test-mode public API key**.
- [ ] **Live-mode keys:** Same page — note the live-mode public key for later. DO NOT use the live key until UAT passes.
- [ ] **Shipping config:** Shipping → Add Method:
  - Method 1: "USPS Standard" — flat rate $9.00 — region: US (recommend; owner discretion)
  - Method 2: "Canada Standard" — flat rate (owner picks; e.g. $19) — region: Canada
  - Method 3: "International — Contact us" — disable purchase outside US/Canada via Snipcart's region restrictions (per CONTEXT D-04)
  - Method 4: "Local pickup at studio" — $0 — region: US (Snipcart supports $0 custom shipping methods per support docs)
- [ ] **Webhook config:** Webhooks → Add endpoint:
  - URL: `https://shapesmith.studio/.netlify/functions/snipcart-order-webhook`
  - Events: subscribe to `order.completed` ONLY (do not subscribe to all events).
- [ ] **Default email:** Notifications → ensure default order-completed email to owner is enabled.

## C. Code-side test-mode key paste

- [ ] Commit with message `feat(05): paste Snipcart test-mode public key into index.html`.
- [ ] Push to dev branch (or whichever branch deploys to the preview).

## E. Deploy preview

- [ ] After step C commit lands, wait for Netlify to build the deploy preview.
- [ ] Open the preview URL.
- [ ] Confirm `/shop` renders the catalog grid (not Coming Soon).
- [ ] Move on to UAT (`05-UAT.md`).

## F. Launch (post-UAT, optional in this plan)
