## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Drop `--openssl-legacy-provider` everywhere | Pitfall 7. Flag is webpack-4-era crypto workaround; Vite uses esbuild + Rollup which use modern Node crypto natively. Node 22+ has removed the flag — keeping it would cause `unknown option` errors on a Node 22 build host. |
| `start` aliased to `vite` (alongside canonical `dev`) | Owner muscle memory + any external doc references (README, screencasts) keep working. `dev` is the modern Vite convention so it's also exposed. Two scripts pointing at the same binary cost nothing. |
| Vitest `test` runs `vitest run` (single-pass), not `vitest` (watch) | Local-default + CI-default consistency. Watch mode lives at `test:watch` for explicit opt-in. Matches the CRA `react-scripts test` behavior modulo Jest's interactive-watch default (which CRA never enabled in CI). |
| Did NOT add `@vitest/coverage-v8` | Coverage is explicitly out of scope per RESEARCH.md / PLAN.md Task 1 §"Do NOT add @vitest/coverage-v8". Plan 04-03 can revisit when needed. |
| Did NOT add Pitfall 4 / Pitfall 5 defensive shims | Build succeeded clean with the Plan 04-01 vite.config.js as-is. Adding `define: { 'process.env': '{}' }` or `optimizeDeps.include: ['@sanity/client']` pre-emptively adds config surface without verified need. Plan 04-05 (deploy preview) is the right place to surface a real runtime regression. |
| Empty commit for Task 3 | Task 3 modifies no files but is a real task with a real verification gate (`pnpm build` exit 0 + 11 grep assertions on `build/index.html`). The empty commit honors the per-task atomic commit protocol so the SUMMARY can cite a hash for the build verification step. |
| Server-side env vars unrenamed | Hard constraint from executor prompt + PLAN.md Task 2 §DO NOT. `RESEND_API_KEY` + `RECAPTCHA_SECRET_KEY` (in `netlify/functions/submit-quote/submit-quote.js` lines 23 + 84) have no `REACT_APP_` prefix and are consumed by the Netlify Function (Node runtime, not browser). Renaming them would force a coordinated dashboard change that this plan has no business making. |

## Issues Encountered

- **Non-fatal PostCSS warning during build (out of scope, deferred):** Vite's PostCSS pipeline emitted a warning for `src/css/tailwind.css` line 5:

  ```
  [vite:css][postcss] @import must precede all other statements (besides @charset or empty @layer)
  3  |  @tailwind utilities;
  4  |
  5  |  @import url("https://fonts.googleapis.com/css2?family=Poppins:wght@400;700;900&display=swap");
     |  ^
  ```

  The Google Fonts `@import` comes AFTER the `@tailwind` directives in the source CSS. The CRA-era PostCSS pipeline silently tolerated this; Vite's pipeline issues the warning but still emits a complete CSS file. Reordering the `@import` to the top is a CSS hygiene task — Phase 4's "no user-visible change" success criterion means we should NOT touch font-loading behavior in this phase. Filed for Plan 04-04 cleanup or a separate follow-up.

- **`whatwg-encoding@3.1.1` deprecation noted by pnpm:** Pulled in transitively by `jsdom@25`. Non-blocking; `jsdom` upstream owns the upgrade. No action required in this plan.
